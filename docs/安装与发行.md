## 历史：0.6.0 开源数据测试安装包

`dist/BihuaInput-0.6.0-setup.exe` 为 Windows x64 测试安装程序，包含 32/64 位 TSF、后台、Rime、Python、原生设置、开源生成 profile、许可证和对应源码。`dist` 同时提供 `BihuaInput-0.6.0-source.zip`、SHA256、安装说明及 `BihuaInput-0.6.0-validation.json`；构建说明见 `packaging/BUILD.md`。开源数据由 Conway 固定提交生成，来源和哈希见 `packaging/open-data.lock.json`，不包含本机商业研究表、个人词库或学习记录，排序与本机研究版不同。

安装程序使用真实 `%LOCALAPPDATA%/BihuaWeasel/0.6.0` 用户目录；需要时提升权限注册 `%ProgramFiles%/BihuaInputMethod/0.5.3` 中的共享前端。升级保留本机研究 profile 与个人资料；卸载按所有权恢复安装前用户配置并保留用户后来修改的文件、个人数据、备份和共享 TSF 组件，不做完整机器级清除。安装事务由 `packaging/Install-Release.py` 管理，备份在 `BihuaWeasel/installer-backups`。

最终 exe 已在中文空格新目录执行 `/validate`，152 项文件校验、真实 Rime 输入和原生设置检查通过。首装、升级、失败回滚及卸载数据保留的事务回归通过，但 Windows 接口为模拟；验证模式不注册 TSF、不修改真实用户资料。本次交付未改变当前本机安装。安装包尚未签名，干净 Windows 首次注册、UAC、实际注销与重启、真实完整升级卸载及重装仍待验收，交付为测试版。下述 0.5.2 私有修复包属于另一份本机材料，仍不得分发。

## 当前本机修复

0.5.2 已从 Codex 外安装到真实的 `%LOCALAPPDATA%/BihuaWeasel/0.5.2`，数据位于真实 `%APPDATA%/Rime`。设置页面、词库管理脚本、标准码表及 Python 运行库随程序安装，不依赖项目目录或用户自行安装 Python。Windows 用户登录任务 `BihuaInputMethod` 启动后台；Run 项请求同一任务，避免重复启动。后台父进程为 Windows 的 svchost.exe。

0.5.0/0.5.1 曾写入 Codex MSIX 的 LocalCache。旧报告能证明该开发视图的功能，不能证明操作系统实际安装。后续安装先创建写入探针并核对最终物理路径，发现重定向立即拒绝。注册、运行、设置保存及菜单资源检查必须由 Codex 外部进程执行。

本机联想记录和个人 TSV 已迁移到真实用户目录，已有真实数据不会被覆盖；本次原有133个手输事件在后续真实输入150个事件时仍完整保留。缓存中的原生词组/容错 UserDb 另存到安装目录 migration-preserved，不依赖保留 Codex 缓存。它们尚未与真实运行中生成的原生 UserDb 合并，不声称旧原生词频已经全部恢复到当前排序。

恢复脚本 `Restore-Independent.py` 默认只预览；应用前检查注册所有权，恢复安装前注册和已有配置，保留个人数据、备份和程序包。真实卸载未在用户当前工作环境执行。外部验收证据是 `.verification/independent-install-results.json`、`independent-runtime-results.json` 和 `physical-install-results.json`。

## 给其他人安装

对外提供单个安装程序，包含 Windows 输入法前端、Rime、笔画方案、设置页面、运行库和允许发行的数据。用户下载、安装、按系统要求重新登录后，Win＋空格应能直接选择“笔画输入法”。不得要求用户装 Codex、运行项目脚本或手动编辑 YAML。

首装必须注册自己的 TSF 身份、语言配置与类别，不能仅覆盖已经装好的小狼毫 COM 路径。升级保留个人数据，安装失败恢复原注册；卸载只清理自己仍拥有的注册和启动项，个人数据默认保留。旧小狼毫安装可保留作恢复来源，自己的菜单仅“笔画输入法”“笔画设置”。

`.verification/independent-package-0.5.2` 含个人迁移材料，不作为发行输入。当前发布数据由固定快照重新生成，代码及第三方来源单独说明，不读取真实 Rime 用户目录，不打包个人记录。

## 发布验收

以下全部通过，才能称为可发布安装包：

- 没有 Codex、Python、小狼毫的干净 Windows 电脑可以完成首装。
- 当前应用、任务栏以及 Win＋空格均使用自己的身份和简化菜单。
- 关闭开发工具、注销登录及重启电脑后仍能输入，后台不会变回原版。

- 发行包使用用户指定且哈希锁定的基础数据，不含个人数据；全新目录的候选排序与产品参考一致。

独立 TSF 前端 0.5.3 已安装到 `%ProgramFiles%/BihuaInputMethod/0.5.3`，与后台 0.5.2 配合。它使用固定独立 CLSID/profile，受保护的机器级注册需要管理员批准；仅为当前用户启用、设为中文默认，并停用原小狼毫入口。前端断线时请求同一 Windows 启动任务，避免恢复到原版或依附开发进程。

回车与小键盘 Enter 确认后停止本轮联想并收起候选；空格继续逐字联想。真实 Rime 测试见 `enter-close-tests.json`。默认中文配置在启用完成后设置，防止首次激活改写先前设置。

## 2026-10-15 按键风格与原生设置

默认设置入口现在运行内置 Python 的 Native-Settings.py，使用 Win32 原生控件弹出独立窗口，不启动浏览器或 HTTP 服务。网页设置可通过 Open-Settings.ps1 -Web 显式使用；-NoBrowser 仍供维护验证。风格与自定义绑定由 key_bindings.py 统一校验，编译后回读并沿用失败回滚。

真实安装更新报告：`.verification/key-style-install.json`；已安装原生窗口测试：`installed-native-settings-smoke.json`；三风格真实 Rime 与原生焦点边界：`key-style-standard.json`、`key-style-alternative.json`、`key-style-custom.json`、`key-style-focus-native.json`。设置 API 保存/回滚/重复键与保留键拒绝测试：`key-style-settings-tests.json`。原生窗口测试验证控件、预设/自定义与预览，不冒充人工桌面视觉或跨应用按键实测。

焦点边界在关闭联想时也设置 keymap_reset，避免按住点切换窗口后残留选字状态。更新的服务仍由原 Windows 任务独立启动；不改变现有词库数据。


## 原生设置显示与按键录入修复

Native-Settings.py 使用浅色留白、墨绿选中态、两列键帽式录入。字母与小键盘各两套预设直接展示；绑定按钮点击后用临时键盘钩子捕获物理虚拟键，主键盘数字不当作小键盘数字。钩子仅在录入期间、本窗口前台处理按键，Esc、失焦、换页、关闭都卸钩；系统快捷键放行并退出录入。不在设置之外记录按键。

SendMessageW 的 UTF-16 缓冲区必须保留到同步调用返回，不能从临时 ctypes 对象提取地址后立即释放。下拉与词库列表统一使用持有缓冲区的 send_text。测试对所有保留下拉逐项调用 CB_GETLBTEXT 读回文字，避免只测选项索引却漏掉显示乱码。

实际安装报告 native-settings-redesign-install.json、新版控件测试 installed-native-settings-redesign-smoke.json 及对应应用自身渲染 PNG 位于 .verification。测试覆盖共同的按键事件处理函数、重复/保留/设备限制、取消与失焦卸钩；没有伪称人工按过所有实体键盘。界面更新不重新部署输入方案，不改配置及个人数据。


## 2026-10-16 数字风格保存与高清布局

Rime 编译 YAML 时把纯数字风格名 `789456` 输出成整数标量；设置页先前用字符串直接比较，误报 keypad_style 未加载并回滚。风格标识在状态及编译回读边界归一化为字符串，其余映射、布尔与数值校验仍严格比较。Test-Settings-Panel 模拟该编译行为，修复前复现同一报错，修复后通过。外部真实安装实际保存 789456，读回 compiled_style_type=int，随后恢复原设置。

窗口在创建任何 HWND 前设置 PerMonitorV2 DPI 感知，按当前 DPI 直接创建字体与控件；跨屏 WM_DPICHANGED 重新创建字体并移动控件，按对应显示器工作区限制尺寸。去除 Windows 位图放大造成的模糊。本机已验证 144 DPI / 150%，实际字体读回 Microsoft YaHei UI；另在控件内测试 96/120/144/192 的布局重排，不将其说成实体多屏切换实测。

键盘页分离笔画符号与名称，对齐双列键帽，预设用实色选中态，正文改中性深色，重排说明与底部操作。证据：.verification/numeric-style-after.json、hdpi-settings-install.json、installed-hdpi-settings-smoke.json 及同名 PNG。新版已从实际菜单入口打开，输入法配置与个人数据保持原样。
