# 本地联想的选择反馈

采用用户指定的明确分数：初始10、选择+1、本回合实际展示未选−1、上限20；10以下按分数逐渐后移，0隐藏。全部静态、临时、个人来源均受反馈覆盖。数值属于可调产品规则，没有论文证明它们是中文笔画输入的最优参数。

[Cascading Bandits, ICML 2015](https://proceedings.mlr.press/v37/kveton15.html) 将列表选择建模为部分观察，说明不能把所有召回项都当作用户检查过。这里借鉴曝光边界，而没有声称实现其UCB算法：仅记录真正显示的页，同一回合去重，不翻到的页不扣分。菜单可见是工程上的曝光代理，并不证明眼睛逐项看过。

[HCINLP 2021 的文本预测交互研究](https://aclanthology.org/2021.hcinlp-1.18.pdf) 记录了用户忽略推荐、继续键入等行为。该先导研究规模较小、场景为英文写作，因此不能把“没点”当作确定不喜欢。本实现按用户要求使用−1，但区分中性窗口切换、重复重绘、未知字母与明确继续手输／取消。

[Thompson Sampling 教程](https://arxiv.org/abs/1707.02038) 的贝叶斯方法可以平滑稀疏点击反馈，并在不确定项目上探索。但它会引入随机排序，而且后验概率通常不达到精确0；这与用户要求的硬上限、0隐藏和稳定候选冲突。MVP采用确定性评分，后续如收集足够的本地选择率和目标字页数，可比较较轻的负反馈或位置折扣，不默认加入随机探索。

每次选字对当前有效上下文至下一字的关系计分；最长已反馈上下文的身份和分数优先，排名缓存不负责遗忘。负反馈记录不等于正式个人词条。0分的记录保留隐藏标记，避免短上下文或静态候选绕回；隐藏之后新手输观察可形成待唤醒候选，明确接受后恢复10。

每个展示回合只结算一次：选择推荐时所选+1、其余显示−1；继续普通笔画或取消时显示项−1；失焦、切换方案和关闭会话中性放弃。每页9个、最多5页。重新初始化不加分，也不按日历扣分。前后文训练仍只保留最近1000个手输字，推荐字形成断点。

v1迁移时仅计算一次旧有效权重。旧可见已接受关系映射到10–20分，保留原相对强弱而不凭空制造拒绝历史；旧隐藏关系映射0。内容版本升级为2，文件名保持不变。原生UserDb锁、校验和、pending原子替换、previous恢复和版本冲突回退均保留。
